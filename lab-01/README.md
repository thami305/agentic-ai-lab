# Lab 1 — Deterministic tool-using assistant

Week 1 of the Agentic AI field plan. A CLI agent that inspects a small SQLite
"client pipeline", calculates a metric deterministically, and returns a typed
recommendation. Tools are read-only; the loop is bounded, validated, and traced.

## Quickstart

```bash
cd agentic-ai-lab/lab-01
python3 -m venv .venv && .venv/bin/pip install -q pydantic pytest

# seed the demo database
.venv/bin/python src/lab01/db.py data/pipeline.db

# watch it work (deterministic demos, no API key needed)
.venv/bin/python -m lab01.run --demo acme      # add src to path: PYTHONPATH=src
.venv/bin/python -m lab01.run --demo globex    # injection-resistance demo

# run the 20 acceptance tests
PYTHONPATH=src .venv/bin/python -m pytest tests -q
```

(Or from the repo root: `PYTHONPATH=src .venv/bin/python -m lab01.run ...` —
`run.py` adds `src` to `sys.path` itself when invoked as a module.)

## Using a real model

```bash
pip install openai   # or: pip install anthropic
export OPENAI_API_KEY=...        # via your secure vault, never in a file
export LAB_MODEL=<current-model-id>
PYTHONPATH=src .venv/bin/python -m lab01.run --model openai \
  "What is Initech's win rate, and what should we do?"
```

The model must return its final answer as JSON matching the `Recommendation`
(or `Decline`) schema; anything else fails the run loudly.

## Layout

```
lab-01/
  src/lab01/
    agent.py    # the control loop: allow-list, validation, timeout/retry,
                #   duplicate caching, final-answer condition, tracing
    tools.py    # read-only SQLite tools + registry (the allow-list)
    schemas.py  # Pydantic contracts for tool args and the final answer
    models.py   # backends: ScriptedStub (tests) + OpenAI/Anthropic adapters
    db.py       # deterministic seed data (includes one injection payload)
    run.py      # CLI
  tests/test_lab01.py   # 20 acceptance cases
  docs/architecture.md  # design notes + sequence diagram + test report
  data/pipeline.db      # generated by --seed (not committed)
```

## What "done" means (from the plan)

- [x] 20 fixed cases run unattended (`pytest tests -q`)
- [x] No unauthorized tool executes (tests 7, 8)
- [x] All outputs validate against Pydantic schemas (tests 16, 19)
- [x] Failures return a safe, useful error (tests 7–11, 15, 16)
- [x] Token and latency totals captured on every run (test 20)
- [x] Sequence diagram + failed-trace analysis (`docs/architecture.md`)
- [ ] Two-minute demo recording — record when walking through the demos
