# Lab 8 — One task, three orchestration patterns

Week 8 of the Agentic AI field plan. The same task — review a synthetic
vendor proposal into a structured `Review` (verdict, findings with severity
and verbatim evidence, risks) — implemented three ways and measured
head-to-head:

- **Pattern A**: single agent with tools (a compact generic loop in lab08).
- **Pattern B**: manager + two specialists, explicit typed handoffs,
  restricted tool registries per specialist.
- **Pattern C**: explicit graph with deterministic routing
  (validate → extract → assess → review → publish, conflict → human review),
  reusing `lab03.graph.Graph`.

Teaching model, as always: *the model proposes, deterministic code decides.*
Every pattern's review passes through `validate_review` — schema-valid plus
every finding cited with a verbatim quote — before it may ship.

## Quickstart

```bash
cd agentic-ai-lab/lab-08
python3 -m venv .venv && .venv/bin/pip install -q pydantic pytest

# measure: 5 seeded runs per pattern, comparison table, generates docs/adr.md
PYTHONPATH=src:../lab-02/src:../lab-03/src .venv/bin/python -m lab08.evaluate

# run the 22 acceptance tests
PYTHONPATH=src:../lab-02/src:../lab-03/src .venv/bin/python -m pytest tests -q
```

All runs are deterministic: stub backends only, no network, no API key.
Stochasticity enters solely via `SeededStub(seed)` — `random.Random(seed)`
varies which findings get included/dropped, verdict jitter, and token
counts — so per-seed results reproduce exactly and the reported variance is
honest.

## The task

Given the synthetic vendor proposal (`data/proposal.txt`: Pricing, Terms,
Delivery/SLA sections; planted issues include a vague "best efforts" SLA,
uncapped price escalation, an auto-renewal clause, a missing liability cap,
and a termination fee), produce:

```json
{verdict: "accept|revise|reject",
 findings: [{claim, severity: "high|medium|low",
             evidence: {passage_id, quote}}],
 risks: ["..."]}
```

Every finding cites a proposal passage (`PROP-P1` …) with a **verbatim**
quote; the deterministic validator rejects anything else.
