# Lab 9 — Golden set and trace-driven regression

Week 9 of the Agentic AI field plan. A 50-case versioned golden set over the
lab-02 agent and the lab-03 graph, a span tracer that instruments runs without
modifying lab-02/lab-03 source, deterministic scoring, a stub "model grader"
with documented limits, and a merge gate driven by thresholds from
`eval/thresholds.json`.

The teaching model, applied to the lab itself: the model proposes (case
inputs, briefs), deterministic code decides (schema, citations, terminal,
tool allow-list — then the gate).

## Quickstart

```bash
cd agentic-ai-lab/lab-09
python3 -m venv .venv && .venv/bin/pip install -q pydantic pytest

# run the 50-case golden set and emit one JSON trace per case
PYTHONPATH=src:../lab-02/src:../lab-03/src .venv/bin/python -m lab09.run_golden

# the merge gate: green or red, per threshold
PYTHONPATH=src:../lab-02/src:../lab-03/src .venv/bin/python eval/gate.py

# regenerate the golden set (record-and-pin; review data/golden.jsonl after)
PYTHONPATH=src:../lab-02/src:../lab-03/src .venv/bin/python scripts/gen_golden.py

# run the 17 acceptance tests
PYTHONPATH=src:../lab-02/src:../lab-03/src .venv/bin/python -m pytest tests -q
```

All tests are deterministic: stub backends only, no network, no API key.
Lab-02/lab-03 modules are reused read-only via `sys.path` — this lab never
modifies their sources.

## Layout

```
src/lab09/
  tracer.py      # span tracer; wraps backend.next(), tool fns, graph node fns
  runner.py      # runs golden cases, scores deterministic checks
  grader.py      # StubGrader (surface properties only) + calibration
  gate.py        # merge gate; thresholds loaded from eval/thresholds.json
  run_golden.py  # CLI: run golden set, write traces/<case_id>.json
tests/           # 17 acceptance tests (see "What done means")
docs/architecture.md
data/
  golden.jsonl       # 50 versioned cases (generated by scripts/gen_golden.py)
  calibration.jsonl  # 10 labeled entries for grader calibration
eval/
  thresholds.json  # {"min_pass_rate": 1.0, "max_unsupported_claims": 0,
                   #  "min_agreement": 0.9}
  gate.py          # thin wrapper around src/lab09/gate.py
scripts/gen_golden.py
traces/            # one JSON trace per case (generated, not hand-written)
```

A case: `{id, version, category, target, input, expectations}`.
Categories: `happy_paths`, `ambiguous`, `missing_data`, `tool_errors`,
`adversarial`, `previously_observed_failures` (bad citation, fabricated
quote, injection payload, conflicting evidence, budget blowout, empty
question — drawn from labs 1–3).

## What done means

- [x] 50 versioned cases in `data/golden.jsonl`, one JSON object per line,
      every case carrying `version`, `category`, and `expectations`; ids unique.
- [x] Tracer records spans per run (`model`/`tool`/`retry`/`error`/`path`),
      one JSON trace per case (`traces/*.json` via `run_golden.py`; tests use
      it in-memory), plus the path taken.
- [x] Deterministic checks per case, scored before any grading: schema valid,
      citations validate, expected terminal reached, no unexpected tool calls.
- [x] `StubGrader` with documented limits (see `grader.py` docstring and
      `docs/architecture.md`), calibrated on a labeled subset; agreement with
      the deterministic checks asserted >= threshold.
- [x] Gate reads thresholds from `eval/thresholds.json` (not hardcoded) and
      returns red/green per threshold.
- [x] Centerpiece regression test: monkeypatch `lab02.agent.validate_brief`
      to always return ok (citation post-validator disabled) → gate FAILS
      (red); remove the patch → gate green. "A prompt, model, or tool change
      cannot merge unless thresholds stay green."
- [x] `PYTHONPATH=src:../lab-02/src:../lab-03/src .venv/bin/python -m pytest tests -q`
      green (17 tests).
